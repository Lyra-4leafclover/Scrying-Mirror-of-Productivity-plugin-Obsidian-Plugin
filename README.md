# ✧ Scrying Mirror of Productivity (Obsidian Plugin) ✧

> An obsidian luxury focus chrono, task matrix, lecture theater, telemetry engine, and journal studio with 2-way markdown vault sync.

---

## ✨ Features

- **Directives & Task Matrix**: Add tasks with priority badges (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`) that sync directly to `ScryingMirror/Tasks.md` in markdown format (`- [ ] task`).
- **Focus Flow Chrono**: Circular SVG Pomodoro timer with Focus (25m), Short Break (5m), and Long Break (15m) modes.
- **Lecture Theater & Scratchpad**: Side-by-side YouTube study stream with auto-saving notes synced to `ScryingMirror/Lectures/`.
- **Liquid Writings Studio**: Personal engineering and reflection logs saved directly as markdown notes with YAML frontmatter.
- **Native Theme Adaptation**: Automatically inherits your Obsidian theme's exact color palette (`--background-primary`, `--interactive-accent`, etc.).

---

## 📦 Installation

### From Community Plugins (Coming Soon)
1. Open Obsidian **Settings** ➔ **Community plugins**.
2. Search for **`Scrying Mirror of Productivity`**.
3. Click **Install**, then **Enable**.

### Manual Installation
1. Download `main.js`, `manifest.json`, and `styles.css` from the latest release.
2. Place them in your vault at `.obsidian/plugins/obsidian-scrying-mirror/`.
3. In Obsidian, go to **Settings** ➔ **Community plugins** ➔ toggle **Scrying Mirror of Productivity** to **ON**.
